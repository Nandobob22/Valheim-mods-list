# Valheim Mods Summary

This list groups the mods by the part of Valheim they change. **Gameplay-changing mods** are separated from **quality-of-life, building, visual, and technical mods**, so players can quickly understand what they're actually installing.

## ⚙️ Mod Libraries & Dependencies

These aren't really "gameplay mods." They're libraries that other mods use behind the scenes. **Your friends generally don't need to understand or configure these.**

* [Jotunn](https://thunderstore.io/c/valheim/p/ValheimModding/Jotunn/) — Core modding library used by many Valheim mods.
* [HookGenPatcher](https://thunderstore.io/c/valheim/p/ValheimModding/HookGenPatcher/) — Generates files required by certain mods to modify Valheim's code.
* [JsonDotNET](https://thunderstore.io/c/valheim/p/ValheimModding/JsonDotNET/) — Shared JSON library used by Valheim mods.
* [YamlDotNet](https://thunderstore.io/c/valheim/p/ValheimModding/YamlDotNET/) — Shared YAML library used by Valheim mods.
* [Zen ModLib](https://thunderstore.io/c/valheim/p/ZenDragon/Zen_ModLib/) — Shared library used by Zen mods.
